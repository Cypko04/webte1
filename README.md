# Moja online vizitka

Meno: Daniel Cyprian  
Krúžok: Pondelok 13:00  
Web: https://webte1.fei.stuba.sk/~xcyprian/

## O projekte

Projekt je osobná webová vizitka vytvorená pomocou HTML5, CSS a JavaScriptu.
Obsahuje môj profil, životopis, záľuby, týždenný rozvrh a interaktívnu mapu.

## Zdroje

- Fotografia profilu: vlastná fotografia upravená s AI
- Fotografia lezeckého vybavenia: vlastná fotografia upravená s AI
- Mapové podklady: OpenStreetMap
- Mapová knižnica: Leaflet
- Font: Inter
- Licencia fontu: SIL Open Font License 1.1
- Favicon: vlastný monogram DC vytvorený s AI

## Použitie AI

Pri tvorbe projektu som použil ChatGPT ako pomoc pri kontrole zadania,
úprave HTML, CSS a JavaScriptu a pri hľadaní a opravovaní chýb.
